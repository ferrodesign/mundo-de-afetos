Política de Privacidade

A presente Política de Privacidade descreve como o Mundo de Afetos, recolhe, utiliza e protege os dados pessoais dos utilizadores que visitam este website, em conformidade com o Regulamento Geral sobre a Proteção de Dados (RGPD).

1. Responsável pelo Tratamento de Dados

Mundo de Afetos
Titular: Teresa Antunes
Localização: Alpiarça, Santarém, Portugal
Email: mundodeafetos@hotmail.com

2. Dados Pessoais Recolhidos

Este website não recolhe dados pessoais através de formulários ou sistemas de pagamento. Qualquer contacto é realizado por meios externos ao website (telefone ou email).

3. Finalidade do Tratamento

Os dados eventualmente fornecidos pelo utilizador através de contacto direto são utilizados exclusivamente para responder a pedidos de informação sobre os serviços prestados.

4. Conservação dos Dados

Os dados pessoais são conservados apenas pelo período necessário para a finalidade para a qual foram recolhidos, não sendo utilizados para outros fins.

5. Partilha de Dados

O Mundo de Afetos não partilha, vende ou cede dados pessoais a terceiros.

6. Direitos do Utilizador

O utilizador tem o direito de solicitar o acesso, retificação ou eliminação dos seus dados pessoais, bem como limitar ou opor-se ao seu tratamento, nos termos da legislação em vigor.

7. Cookies

Este website utiliza apenas cookies técnicos essenciais para o seu funcionamento, não recolhendo informações pessoais ou de rastreamento.

8. Alterações à Política de Privacidade

O Mundo de Afetos reserva-se o direito de atualizar esta Política de Privacidade sempre que necessário. Recomenda-se a consulta periódica desta página.

9. Contactos

Para qualquer questão relacionada com esta Política de Privacidade, poderá contactar através do email: mundodeafetos@hotmail.com
